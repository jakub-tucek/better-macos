## Candidate scope

- Editable quick-action widgets, tabbed Settings, and opt-in guided setup.
- A retained right-click menu and keyboard-navigable Window actions/Keep awake
  palettes sharing translucent native presentation.
- Display switching/recovery, arrangement and matched edges; named window layouts
  with optional reconnect/wake restoration.
- Opt-in Rectangle-style window shortcuts: halves, quarters, thirds, two-thirds,
  maximize, almost maximize, center, restore, and display movement. Repeated left/right
  halves traverse neighboring displays, entering the opposite half at each boundary.
- Foreground-app shortcut discovery so unreadable background Finder metadata does
  not block an otherwise eligible focused window; saved layouts keep full-desktop scans.
- Independent microphone/output selection, preferred routes and Bluetooth reconnect
  policies, timed/app-based keep awake, and hold-to-quit protection.
- Paused-by-default clipboard capture, searchable text/PNG history, pins, exclusions,
  and separate opt-in unencrypted JSON retention.
- Opt-in mouse-class runtime tuning, selected animation reductions, and experimental
  menu-bar spacing/hiding.

See [the usage guide](../usage.md) for defaults, permissions
and limits, and [README](../../README.md#install-from-source) for source installation.
The app targets Apple Silicon/macOS 15+; recorded development evidence includes
macOS 26.6.2. We do not claim a notarized binary workflow, universal animation
suppression, per-device mouse/wheel controls, cross-Space window restoration, a
notch-overflow panel, SQLite history, or plugins.

## Safety and reliability work

- Reviewed display-recovery ownership, setup awake-assertion removal, watchdog
  authorization, and unreadable-journal preservation fixes are integrated. See
  [core integration evidence](checklist.md#core-integration--2026-10-15).
- Clipboard Clear confirmation, bounded thumbnails, cleanup retries and unload/quit
  protection remain part of the existing behavior.
- Source builds include complete project/vendor notices before signing. Installer
  signing-identity changes rebuild even at an unchanged source revision, with
  verified staged replacement/rollback. [Packaging evidence](../validation/packaging.md).
- Bluetooth separates helper control evidence from native inventory presentation.
  Contradictory, stale, or incomplete observations block control. The native probe
  is read-only qualification infrastructure; it does not fix reconnect or provide
  a native connection fallback.

## Acceptance limits

Tests with fake backends, fixture renders, source parity, and native compilation
do not establish physical hardware or live accessibility acceptance. See the
[current matrix](../validation/README.md) for remaining display, gesture, audio, mouse,
sleep/lid-close, clipboard focus/shortcut, VoiceOver and UI checks. The whole-desktop
freeze cause and remaining Swift gesture terminal/drain behavior are unresolved;
see [offline gesture evidence](../validation/gesture-terminal-failures.md).
No new app/system actions or full-suite run occurred for this documentation refresh.

Source updates compare commits on `main`, not release versions. The updater pins
the installer download to the offered SHA, but the installer builds latest `main`.
An update does not guarantee an exact offered-SHA build. Ad-hoc signing may require
renewed permission grants after replacement; a signing certificate is not included.
